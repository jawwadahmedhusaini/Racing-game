APEX RUSH 2.6.0 — browser racing game

1. Unzip the complete download.
2. Install Python 3 if it is not already on your computer.
3. Windows: double-click START-WINDOWS.bat.
   macOS/Linux: run `python3 start-game.py` from this folder.
4. Your browser opens the game. Keep the terminal window open while playing.

The launcher only serves files on your own computer. No game account, backend,
API key, additional package download or internet connection is needed to play.
The first Python installation, if needed, is a separate prerequisite.

Controls: W/Up accelerate, hold S/Down brake then reverse, A/D or Left/Right steer,
Space + steering drift, Shift nitro, C camera, R recover, Escape pause.
Manual driving: brake before corners and steer through them. Forward does not
automatically turn the car. Left/right match the chase camera.
Drift to fill nitro. Activate at a full meter for shockwave boost.
Hold brake after stopping to reverse; accelerate to drive forward.
Touch controls include BRAKE / REV and RECOVER. Brake overrides auto-acceleration and nitro.
Release an empty boost to recharge.

The bundled `web` directory is also ready for any static web host at its domain
root. It must be served over HTTP/HTTPS; opening index.html directly does not
load browser modules correctly. Share the hosted edition at:
https://jawwadahmedhusaini.github.io/Racing-game/
(The repository owner must enable GitHub Pages if it is not already active.)

Use a modern browser with WebGL 2 and hardware acceleration. Start with
Medium or Low quality on slower hardware. Browser-local saved progress is tied
to the server address/port you use. Clearing site data erases progress.

Credits and licenses are available in Settings and in web/licenses.
Vanta, Spectre and Stratos adapt the attributed Car Concept asset.
Solstice GT is separately authored; BMW M3 uses an imported community model.
The BMW model is an unofficial recreation. This independent game is not an
Asphalt product. See the individual asset credits and licenses.

Settings now include Adaptive Resolution and a live Performance Display.
Adaptive Resolution keeps your effects preset and adjusts render sharpness
under sustained load. Lower the graphics preset if the frame rate stays low.
Close other APEX RUSH tabs before opening another session; this protects saves.

Race preparation shows progress and can be cancelled with Escape or Cancel.
The countdown begins only after the first race frame is prepared.
